# 365step

Подготовка к поступлению за рубеж в одной программе: IELTS, SAT и шаги поступления — маленькими ежедневными уроками. Плюс годовой курс чтения и письма в духе AP Seminar и друзья, с которыми не хочется пропускать.

```bash
pnpm install        # или npm install
pnpm dev            # http://localhost:3000
```

Базу настраивать не нужно: при первом запросе создаётся SQLite-файл `data/365step.db` со всеми таблицами. На странице входа кнопка **«Войти в демо-аккаунт»** создаёт аккаунт Алии (`demo@365step.app` / `demo1234`) на 7-м дне личного плана (США, IT, 11 класс) — с друзьями, дедлайнами, снаряжением и историей боёв.

## Что внутри

Пять вкладок:

| Вкладка | Что там |
|---|---|
| **Путь** | Личный план подготовки по дням до выпуска (см. ниже), цель дня и серия, планировщик дедлайнов, топ друзей, официальные материалы College Board, IELTS, Common App и UCAS. |
| **Проект** | Семинар по «Франкенштейну» Мэри Шелли: 12 месяцев × (чтение → навык → письменная работа), встроенная читалка романа, портфолио работ. |
| **Друзья** | Таблица рейтинга (неделя / всё время), добавление по email, заявки. |
| **Соревнования** | Учебные гонки по SAT и IELTS: два ученика отвечают на один вопрос, первый верный ответ — шаг по дорожке из пяти клеток. Elo-рейтинг, подбор по уровню, дружеские матчи, магазин из 80 аксессуаров и гардероб для 14 героев. |
| **Конкурсы** | Конкурсы и программы для школьников: официальные ссылки, проверенные сроки, фильтры, избранное и добавление дедлайнов в план. |

### Свой путь для каждого ученика

После регистрации ученик отвечает на четыре вопроса (`/start`, позже — «Изменить цель» в меню):

1. **Куда поступает**: США, Великобритания, Канада, Европа, Азия или «пока не решил». От страны зависят ориентировочный дедлайн подачи и набор эссе (Common App и supplements, UCAS, мотивационное письмо).
2. **Направление**: медицина и биология, инженерия, IT, бизнес и экономика, социальные и гуманитарные, естественные науки или «пока не решил».
3. **Класс** (8–12).
4. **Когда заканчивает школу** — месяц и год. Срок может быть любым: от 3 недель до нескольких лет.

Из этого строится личный план по дням (`src/content/plan.ts` — чистая функция от профиля, без хранения расписания в базе):

- **Подготовка до дедлайна подачи**: английский чередуется по дням (IELTS — Reading, Writing, Vocabulary, Listening, Speaking; SAT Reading & Writing), SAT Math идёт параллельно, шаги поступления привязаны к доле срока (карта и тесты в начале, Personal Statement в середине, финальная проверка перед дедлайном).
- **Тексты по специальности**: короткий академический текст по выбранному направлению и 5 вопросов к нему (главная мысль, детали, True/False/Not Given, лексика, вывод) — по 10 текстов на направление, распределены на весь срок до выпуска. При «пока не решил» — тексты из всех направлений.
- **Финальные 12% до дедлайна** — пробные секции (10 вопросов из пройденного).
- **Практика и повторение заполняют всё время до выпуска**: каждый день есть хотя бы одно задание. Свободные дни занимают уроки практики из банка заданий — по баллам и уровню ученика (см. ниже); каждое пятое — повторение пройденного (6 вопросов из уже открытых уроков).
- Короткий срок — больше заданий в день; длинный — спокойный темп. Нагрузка показывается на странице пути.
- Следующий день открывается, когда пройден предыдущий; внутри дня шаги идут в любом порядке. При смене цели пройденное сохраняется, а план перестраивается от исходной даты старта.

На странице пути развёрнута текущая неделя, соседние недели — строками, дальние месяцы свёрнуты.

Объём контента: **905 вопросов** — IELTS и SAT (по уроку на навык плюс практические уроки), 60 текстов по специальностям × 5 вопросов, 10 наборов академической лексики, 15 уроков по поступлению.

### Баллы, уровень и банк заданий

**Баллы.** После цели — шаг «Твои текущие баллы» (`/start/scores`, позже — «Мои баллы» в меню). Все экзамены необязательны, можно выбрать несколько: SAT (Total 400–1600, R&W и Math 200–800, шаг 10, дата и источник пробника), IELTS Academic (Overall и четыре навыка 0–9, шаг 0.5), TOEFL iBT (0–120 и секции 0–30), Duolingo English Test (10–160), ACT (Composite и секции 1–36). Для каждого — целевой балл и дата экзамена. Проверяются диапазоны, шаги и суммы (R&W + Math = Total, сумма секций TOEFL = Total). Текущее состояние хранится в `student_scores`, каждое изменение — отдельной строкой в `score_history`. При «Пока нет баллов» — диагностика (`/diagnostic`): 12 заданий из банка на секцию (4 базовых, 4 средних, 4 продвинутых), вес 1/2/3.

**Модель уровня** (`src/content/skill-level.ts`, тесты в `skill-level.test.ts`):

- уровень секции: SAT <500 — easy, 500–640 — medium, ≥650 — hard; IELTS <5.5 — easy, 5.5–6.5 — medium, ≥7 — hard;
- TOEFL → IELTS по таблицам ETS (RR-25-02), ACT → SAT по таблицам ACT/College Board 2018, DET → IELTS по таблице Duolingo (источник указан в коде);
- gap = цель − текущий балл; чтобы сравнивать SAT и IELTS, gap делится на ширину уровня (150 баллов SAT, 1.5 бэнда IELTS);
- доля практики секции пропорциональна gap, но не меньше 15%;
- сложность заданий: 20% на уровень ниже, 60% на уровне, 20% выше;
- адаптация: каждые 10 ответов по навыку точность >80% — уровень вверх, <50% — вниз (`skill_stats`).

**Генератор плана.** Свободные дни заполняются уроками практики из банка (`bank/<навык>~<номер>`): секция — по доле gap, навык — по весам доменов College Board, по 8 заданий в миксе сложности. Учитываются только выбранные экзамены. Авторские уроки секции заканчиваются до последних трёх недель перед датой экзамена; в эти недели — пробные секции каждые три дня (`bank/mock~…`) и два самых слабых навыка (`bank/weak~…`). Если для нужной сложности заданий мало, берётся соседняя сложность и нехватка пишется в лог; навык без заданий пропускается с записью в лог.

**Банк заданий** (`src/content/bank/`): схема — `schema.ts` (zod), таксономия — `taxonomy.ts`, по файлу JSON на навык:

| Экзамен | Навыки | Заданий |
|---|---|---|
| SAT Reading & Writing | 11 навыков × 3 уровня × 15 | 495 |
| SAT Math | 19 навыков × 3 уровня × 15 | 855 |
| IELTS Reading | 7 типов вопросов × 3 уровня × 15, 18 текстов | 315 |
| IELTS Writing | Task 1 — 20 (графики, таблицы, процессы, карты), Task 2 — 20 | 40 |
| IELTS Speaking | Part 1, 2, 3 — по 20 | 60 |

Все задания оригинальные; объяснения на русском разбирают, почему верный ответ верен и почему остальные — нет. Задания College Board, Cambridge, Khan Academy и коммерческих пособий не копируются; официальные материалы — ссылками в блоке «Официальные материалы». Цитаты из «Франкенштейна» (общественное достояние) сверяются с текстом романа. IELTS Listening пока работает на авторских уроках с текстовым транскриптом; записанное аудио — TODO.

### Listening и Speaking без звука

- **Listening**: переключатель «🎧 Слушать аудио / 🔇 Не могу слушать». Аудио — это скрипт, озвученный синтезом речи браузера, с разными голосами для разных говорящих, паузой, повтором и скоростью. Во втором режиме тот же скрипт показывается как транскрипт. Вопросы и разбор одинаковые в обоих режимах. Если браузер не умеет синтезировать речь, текстовый режим включается сам.
- **Speaking**: переключатель «🎤 Говорить голосом / ⌨️ Не могу говорить». Голос распознаётся браузером (Web Speech API, лучше всего в Chrome и Edge), вопросы экзаменатора озвучиваются. Во втором режиме идёт тот же диалог, но ответы пишутся текстом. Если ответ слишком короткий, экзаменатор задаёт уточняющий вопрос. В конце — мгновенный разбор по критериям IELTS (связность, связки, лексика, грамматика); с `ANTHROPIC_API_KEY` дополнительно доступна оценка ИИ-экзаменатора с ориентировочными баллами. Если нет микрофона или распознавания речи, текстовый режим включается сам.
- Выбор режима запоминается в браузере.

### Свежие задания

После урока и на его стартовой странице есть кнопка **«Ещё задания по навыку»** (`src/lib/content-engine.ts`):

- **IELTS Reading**: берётся фрагмент статьи Википедии на академическую тему (лицензия CC BY-SA 4.0, с указанием статьи и ссылкой) и к нему составляются вопросы в формате урока.
- **Тексты по специальности**: то же, но статья берётся из списка тем выбранного направления (60 тем).
- **SAT Reading & Writing, SAT Math, IELTS Vocabulary**: составляются новые оригинальные задания в формате и на навык урока; задания самого урока служат образцом.
- Каждый ответ **независимо перепроверяется** вторым запросом, который не видит ключа. Вопросы, где ответы расходятся, отбрасываются.
- Наборы сохраняются и общие для всех учеников: каждый набор генерируется один раз. Лимит — 6 новых наборов на ученика в день.
- Нужен `ANTHROPIC_API_KEY`. Без него кнопка скрыта, а в уроках остаются ссылки на официальные материалы.

**Почему официальные задания не подтягиваются автоматически.** Задания College Board (SAT) и Cambridge, British Council и IDP (IELTS) защищены авторским правом, и открытого API для них нет. Поэтому в каждом уроке есть прямая ссылка на официальный банк: Student Question Bank и Bluebook для SAT, sample questions на ielts.org и материалы Cambridge для IELTS, Common App и UCAS для эссе.

### SAT

На странице «Путь» есть отдельный практикум **«Desmos для SAT Math»**: 8 уроков, 40 собственных упражнений, официальные инструкции и видео Desmos и практика College Board. Темы: ввод выражений, графики и масштаб, уравнения и системы, параболы, параметры, таблицы, регрессии и экзаменационная стратегия. Калькулятор работает рядом с объяснением ещё до перехода к заданиям.

Уроки практикума доступны после выбора цели. Их завершение сохраняется и приносит очки; кнопка «Продолжить» ведёт к следующему уроку Desmos. Они хранятся в `Plan.tutorials`, отдельно от календарных дней, поэтому добавление практикума не переносит старые уроки, не сбрасывает текущий день и не подмешивает вопросы об интерфейсе в пробные секции. Контент — `src/content/sat-desmos.ts`, источники проверены 17 октября 2026.

В заданиях SAT Math (включая математические повторения, пробные секции и свежую практику) кнопка **Desmos** открывает экзаменационный графический калькулятор. Он открывается справа от задачи в отдельной панели: условие и поле ответа остаются слева, доступны для просмотра и ввода. Полноэкранного раскрытия нет; ширина обеих колонок подстраивается под окно. Выражения сохраняются при закрытии панели и переходе к следующему вопросу в пределах урока. Калькулятор загружается с официального сайта Desmos и требует интернета; также есть ссылка на отдельную вкладку.

Структура цифрового SAT от College Board: 4 домена Reading and Writing (11 навыков) и 4 домена Math (19 навыков), один урок на навык.

### Семинар (AP Seminar–style)

Роман находится в общественном достоянии (Project Gutenberg #84) и встроен целиком — `src/content/frankenstein.json`. Двенадцать месяцев идут по рамке QUEST, от исследовательских вопросов до итоговой работы на 600–1000 слов.

### Письменные работы

Мгновенная проверка черновика в браузере (`src/lib/writing.ts`) настроена под каждый тип задания: IELTS Task 1 (overview, данные, без мнения), IELTS Task 2 (позиция, абзацы, связки, заключение), эссе для поступления (конкретика, рефлексия, клише, лимит 650 слов), список активностей Common App (до 150 знаков в строке), UCAS (три ответа, до 4 000 знаков), эссе семинара (цитаты, ссылки на главы, разбор). С `ANTHROPIC_API_KEY` Claude даёт отзыв как преподаватель и никогда не переписывает текст за ученика.

### Очки, серия, соревнования

- Урок: 10 + 5 за каждый верный ответ с первой попытки + 10 за урок без ошибок. Повтор: 5 очков, раз в день на урок. Письменная работа: 40. Speaking: 30. Свежая практика: 2 за верный ответ, один раз на набор. Очки — это и монеты для магазина.
- Ответы перепроверяет сервер, поэтому подделанный запрос лишних очков не даст.
- Очки хранятся в журнале (`points`): заработок — положительные записи, покупки — отрицательные. Уровень и таблица друзей считаются по заработанному, так что траты их не уменьшают.

**Гонка** (`src/lib/race-rules.ts`, `src/lib/race.ts`). Две параллельные дорожки: старт, пять клеток, финиш. Оба получают один и тот же вопрос; первый верный ответ двигает автора на клетку и закрывает раунд для обоих; неверный ответ блокирует попытку до следующего вопроса; если оба ошиблись или время вышло, никто не двигается. Побеждает тот, кто первым пройдёт пять клеток.

- Всё решает сервер: открывает раунды, выдаёт вопрос (без ответа и объяснения), проверяет ответы, определяет первого и завершает гонку. Клиенты опрашивают `/api/race/[id]` раз в ~0,9 с.
- «Первый» честен к медленной связи: часы каждого стартуют, когда сервер отдал ему вопрос (не позже чем через 5 с после открытия раунда), и побеждает меньшее время реакции, а не пакет, пришедший раньше. Верный ответ ждёт, пока у соперника истечёт столько же времени.
- Все изменения — условные `UPDATE … RETURNING` в транзакциях: раунд, шаг, финиш, рейтинг и монеты фиксируются ровно один раз, даже если оба ученика опрашивают сервер одновременно.
- Выход из гонки — победа сопернику; соперник, пропавший больше чем на минуту, проигрывает; гонка длится не больше 15 минут (затем побеждает лидер или ничья). Незавершённая гонка видна в лобби, в неё можно вернуться.
- **Вопросы.** SAT: Math и Reading and Writing из банка (множественный выбор и grid-in). IELTS: Reading из банка и Listening из набора гонок (`src/content/race/ielts-listening.json`, 45 оригинальных записей, по 15 на уровень). Writing и Speaking в гонках нет — их нельзя честно проверить автоматически. У каждого вопроса тема, уровень и объяснение; все задания — оригинальные материалы 365step, не официальные.
- **Аудио Listening** синтезировано Piper TTS голосами, обученными на записях в общественном достоянии: `en_GB-cori-high` (LibriVox) и `en_US-ljspeech-high` (LJ Speech). Файлы MP3 в `public/audio/listening`, длительности — в `listening-audio.json`; пересборка — `scripts/listening-audio.py`. Каждую запись можно прослушать два раза; время на ответ = 2 × длина записи + 25 с, одинаково для обоих.
- **Рейтинг Elo** отдельно для SAT и IELTS: старт 1000, K = 40 первые 10 игр, потом 24. Победа над более сильным даёт больше, поражение более слабому отнимает больше. Дружеские матчи с друзьями рейтинг не меняют.
- **Подбор соперника**: тот же экзамен, ближайший рейтинг в окне ±100, окно расширяется на 50 каждые 5 с ожидания, но не больше ±400. Поиск можно отменить; закрытая вкладка выходит из очереди.
- **Сложность** матча — из среднего рейтинга обоих: до 750 только простые, около 1100 средние, от 1450 сложные, между ними доля сложного уровня растёт плавно. Вопросы, которые кто-то из пары видел за 30 дней, не повторяются.
- **Калибровка**: шесть вопросов от простых к сложным без соперника, стартовый рейтинг 700–1300.
- **Монеты за гонку**: победа 20, ничья 10, участие 6, только первые 5 соревнований в день. Вышедший сам ничего не получает; гонка, прерванная до трёх сыгранных раундов, не платит никому.
- После гонки — разбор каждого раунда (ответы и время обоих, правильный ответ, объяснение) и темы для повторения.

**Магазин и гардероб** (`src/lib/shop-items.ts`, `src/components/arena/hero-accessories.tsx`). 80 предметов в семи категориях: головные уборы, очки, шарфы/бабочки/бантики/наушники, рюкзаки и дополнения, расцветки и узоры, фоны и рамки, эффекты победы. Всё только украшает героя. Предметы садятся по «оснастке» вида: шляпы — на макушку по ширине головы (кепки и шапки вырезаются из контура головы), очки — на глаза, шарфы и бабочки — на линию шеи под ртом, предметы — в лапу, крыло, плавник или клешню. Покупка блокирует строку героя, запись в гардеробе — заявка на предмет, баланс проверяется после неё в той же транзакции: двойное списание и минус невозможны.

**Миграция боевой арены.** Мечи, шлемы, броня, атака и здоровье удалены. Все монеты, когда-либо потраченные на боевое снаряжение (покупки первой арены и улучшения второй), возвращаются один раз при первом входе в раздел (`arena_refunds`). Старые таблицы боёв больше не пишутся.

Контент лежит в коде, а не в базе: он версионируется вместе с приложением и проверяется типами. В базе хранятся только действия пользователей.

## База данных

- Без `DATABASE_URL` используется SQLite (`data/365step.db`, на Vercel — `/tmp`).
- С `DATABASE_URL` используется PostgreSQL / Supabase. Схема создаётся сама. Вывести её для SQL-редактора: `pnpm -s db:schema`.

На Vercel без `DATABASE_URL` сайт откроется, но данные в `/tmp` живут до холодного старта и не общие между инстансами. Для настоящих пользователей (и особенно для друзей и боёв) нужен Postgres: создайте проект Supabase и задайте `DATABASE_URL` (pooled-строка, порт 6543) в настройках Vercel.

## Персонаж, логотип и каталог возможностей

- Герои арены — оригинальные векторные иллюстрации в коде (`src/components/arena/hero-species.tsx`), без людей в основе. Логотип хранится в `public/brand/step-mark.png`.
- Логотип — зелёная лента, образующая ступени и букву S. Он используется в шапке и favicon. Палитра, шрифт и базовые компоненты интерфейса сохранены.
- Каталог `/opportunities` — редакционная подборка в `src/content/opportunities.ts`, проверенная 17 октября 2026. Точные даты взяты из опубликованных циклов; прошедшие сроки показаны как прошедшие, неизвестные — как необъявленные. Автоматического обновления источников нет.
- Избранное хранится в браузере отдельно для пользователя. Подтверждённый будущий дедлайн можно добавить в существующий планировщик на вкладке «Путь».
- Новые таблицы (гардероб, гонки, рейтинги, очередь) создаются идемпотентно при запуске. Для соревнований на Vercel нужен общий Postgres (`DATABASE_URL`): SQLite в `/tmp` не общий у разных экземпляров функции.
