# 365step

Подготовка к SAT маленькими шагами, годовой курс чтения и письма в духе AP Seminar и друзья, с которыми не хочется пропускать.

```bash
pnpm install        # или npm install
pnpm dev            # http://localhost:3000
```

Базу настраивать не нужно: при первом запросе создаётся SQLite-файл `data/365step.db` со всеми таблицами. На странице входа кнопка **«Войти в демо-аккаунт»** создаёт аккаунт Алии (`demo@365step.app` / `demo1234`) с прогрессом, тремя друзьями, заявкой в друзья, снаряжением и историей боёв.

## Что внутри

В приложении четыре вкладки — раньше их было семь, и в них терялись.

| Вкладка | Что там |
|---|---|
| **Путь** | Дорожка уроков SAT в духе Duolingo. Переключатель Reading & Writing / Math, следующий урок, цель дня, серия, топ друзей за неделю, ссылки на официальную практику College Board. |
| **Проект** | Семинар по «Франкенштейну» Мэри Шелли: 12 месяцев × (чтение → навык → письменная работа), встроенная читалка романа, портфолио сданных работ. |
| **Друзья** | Таблица рейтинга (неделя / всё время): очки, уровень, уроки, серия, счёт на арене. Добавление по email, заявки. |
| **Арена** | 3D-боец (three.js), магазин оружия и щитов за очки, бои с друзьями с 3D-повтором. |

### SAT

Курс повторяет официальную структуру цифрового SAT от College Board: **4 домена Reading and Writing (11 навыков)** и **4 домена Math (19 навыков)**, один урок на навык, всего 150 заданий. Каждый урок — короткая стратегия на русском, задания на английском в формате экзамена (в математике около четверти заданий с вводом ответа, как в Bluebook) и разбор каждого ответа.

Сами официальные задания принадлежат College Board, поэтому они не скопированы в приложение. Вместо этого каждый урок ведёт на [Student Question Bank](https://satsuite.collegeboard.org/practice/student-question-bank), где все официальные задания можно отфильтровать по тому же домену и навыку, а на дорожке есть ссылки на полные пробные тесты в Bluebook и Khan Academy.

### Семинар (AP Seminar–style)

Роман находится в общественном достоянии (Project Gutenberg #84) и встроен целиком — `src/content/frankenstein.json`. Двенадцать месяцев идут по рамке QUEST: вопросы → claim/evidence/commentary → риторика → оценка доказательств → перспективы и линзы → предпосылки → контраргумент → сравнение аргументов → этические линзы → внешние источники → синтез и тезис → итоговая работа на 600–1000 слов.

Письменные задания проверяются сразу, в браузере (`src/lib/writing.ts`): объём, цитаты, ссылки на главы, разбор, контраргумент, внешний источник. Если задан `ANTHROPIC_API_KEY`, появляется кнопка «Получить отзыв»: Claude даёт отзыв как преподаватель и никогда не переписывает текст за ученика.

### Очки, серия, арена

- Урок: 10 + 5 за каждый верный ответ с первой попытки + 10 за урок без ошибок. Повтор: 5 очков, раз в день на урок. Письменная работа: 40.
- Ответы перепроверяет сервер, поэтому подделанный запрос лишних очков не даст.
- Очки хранятся в журнале (`points`): заработок — положительные записи, покупки — отрицательные. Рейтинг и уровень считаются по заработанному, так что покупки их не уменьшают.
- Бой рассчитывается детерминированно (`src/lib/arena-rules.ts`): уровень даёт здоровье, оружие — атаку и шанс крита, щит — броню и шанс блока. Сервер считает бой один раз со случайным seed и сохраняет лог, клиент воспроизводит его в 3D. Баланс проверен симуляцией: при равном снаряжении 50/50, небольшое преимущество около 75%, бой длится примерно 14 ударов. Очки дают только первые 5 боёв в день.

## Устройство

```
src/
  app/
    page.tsx                 лендинг
    (auth)/signin, signup
    (app)/path               вкладка «Путь»
    (app)/seminar            вкладка «Проект» (+ /read/[section] — читалка)
    (app)/friends            вкладка «Друзья»
    (app)/arena              вкладка «Арена» (+ /duel/[id] — повтор боя)
    lesson/[course]/[lesson] плеер урока на весь экран
  content/                   курсы как типизированные модули + текст книги
  actions/                   server actions — единственный путь записи
  components/                UI; arena/ — three.js сцены
  lib/
    db/                      SQLite/Postgres драйвер и схема
    game.ts                  прогресс, очки, серия, письменные работы
    friends.ts               друзья и рейтинг
    arena.ts, arena-rules.ts арена: магазин, бои, баланс
    writing.ts               мгновенная проверка черновика
    ai-feedback.ts           отзыв Claude (опционально)
    demo.ts                  демо-мир
scripts/                     seed, вывод схемы, проверка контента
```

Контент лежит в коде, а не в базе: он версионируется вместе с приложением и проверяется типами. В базе хранятся только действия пользователей.

## База данных

- Без `DATABASE_URL` используется SQLite (`data/365step.db`, на Vercel — `/tmp`).
- С `DATABASE_URL` используется PostgreSQL / Supabase. Схема создаётся сама. Вывести её для SQL-редактора: `pnpm -s db:schema`.

На Vercel без `DATABASE_URL` сайт откроется, но данные в `/tmp` живут до холодного старта и не общие между инстансами. Для настоящих пользователей (и особенно для друзей и боёв) нужен Postgres: создайте проект Supabase и задайте `DATABASE_URL` (pooled-строка, порт 6543) в настройках Vercel.

## Скрипты

| Команда | Что делает |
|---|---|
| `pnpm dev` / `build` / `start` | разработка / сборка / прод-сервер |
| `pnpm typecheck` | `tsc --noEmit` |
| `pnpm check:content` | проверяет весь контент: индексы ответов, уникальность ID, дословное совпадение каждой цитаты из романа с текстом книги |
| `pnpm db:seed` | создаёт демо-мир (если его ещё нет) |
| `pnpm db:schema` | печатает SQL-схему |

## Переменные окружения

Все необязательны, см. `.env.example`: `DATABASE_URL`, `SQLITE_PATH`, `ANTHROPIC_API_KEY`.
